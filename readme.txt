Adds the Pyxd Draping fabric visualizer to selected WooCommerce products.

== Description ==

This standalone plugin loads the Pyxd Draping SDK on eligible WooCommerce
product pages and opens Pyxd's self-contained modal visualizer.

== Installation ==

1. Upload and activate the plugin.
2. Open WooCommerce > Settings > Products > Pyxd Draping.
3. Enter the Company ID supplied by Pyxd.
4. Edit a product, enable Pyxd Draping, and enter its Flexible ID or use the product SKU.
